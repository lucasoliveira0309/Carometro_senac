📸 Carômetro Escolar

Aplicação desktop desenvolvida em Java utilizando Swing para cadastro e gerenciamento de estudantes com foto.

O sistema permite registrar alunos com nome, número de registro (RE) e imagem, armazenando os dados em banco de dados. Também possibilita buscar, editar, excluir registros e listar estudantes de forma dinâmica.

Além disso, conta com geração de relatório em PDF contendo a listagem completa dos alunos com suas respectivas fotos.

🚀 Funcionalidades

Cadastro de estudantes com foto

Busca por RE ou nome (com autocomplete)

Edição e exclusão de registros

Upload e visualização de imagens

Geração de relatório em PDF

Interface gráfica simples e intuitiva

🛠️ Tecnologias utilizadas

Java (Swing)

JDBC (conexão com banco de dados)

iText (geração de PDF)
